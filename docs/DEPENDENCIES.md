# Hatch an Anime: Dependencies

Everything below is **runtime paths** (Roblox Explorer). To find the file for a runtime path, look up its node in `default.project.json` or its `fullpath` in `script-manifest.json`.

## Persistent data (do not rename)

| Store | Type | Owner | Notes |
|---|---|---|---|
| `PlayerData_v1` | DataStore, key `u<UserId>` | `ServerScriptService/PlayerDataService` | Also read and written by `SaveRestore` (owner restore page) and `PlayerPunish` (wipe). Session-locked. |
| `ShopData_v2` | DataStore | `ServerScriptService/ShopService` | Money level, daily streak, boosts, receipts. |
| `ShopData_v1` | DataStore (read-only migration) | `ServerScriptService/ShopService` | Pre-launch data, carried over once. |
| `PanelAdmins_v1` | DataStore | `ServerScriptService/AdminRoles` | Admins added from the owner panel. |
| `CineCamShots_v1` | DataStore | `ServerScriptService/CineCamServer` | Owner camera shots. |
| `StaffServerBackup_v1` | DataStore | `ServerScriptService/StaffServerService` | Fallback for the staff server code. |
| `StaffServerCode_v2` | MemoryStore SortedMap | `ServerScriptService/StaffServerService` | |
| one OrderedDataStore per stat | OrderedDataStore | `ServerScriptService/Leaderboard/LeaderboardService` | Names come from `ReplicatedStorage/Leaderboard/LeaderboardConfig`. |
| `GameGlobalAnnouncements_v1` | MessagingService topic | `ServerScriptService/CrossServerService` | Cross-server announcements, soft shutdown. |

## Remotes created by code

All are created server-side with `FindFirstChild(name) or Instance.new(...)`.

| Remote | Class | Parent | Server handler |
|---|---|---|---|
| `SellEgg` | RemoteFunction | ReplicatedStorage | `EggSellService` |
| `SaveSettings` | RemoteEvent | ReplicatedStorage | `PlayerDataService` |
| `GoHome` | RemoteEvent | ReplicatedStorage | `HomeAndBubbles` |
| `HatchVideo` | RemoteEvent | ReplicatedStorage | `HatchVideoService` (owner) |
| `FirstHatchTutorialAction` | RemoteEvent | ReplicatedStorage | `TutorialProgress` |
| `MoneyCollected` | RemoteEvent | ReplicatedStorage | server→client only (`MoneyStandServer`) |
| `OwnerPanelOpen` | RemoteEvent | ReplicatedStorage | `OwnerPanelServer` |
| `Action`, `Announcement` | RemoteFunction / RemoteEvent | owner-panel folder | `OwnerPanelServer`. `Announcement` is also used by `CrossServerService`. |
| `CineCamRemote`, `CineCamOpen` | RemoteFunction / RemoteEvent | ReplicatedStorage | `CineCamServer` (owner) |
| `ShopRemote` | RemoteFunction | `ReplicatedStorage/ShopSystem` | `ShopService` |
| `InventoryRequest`, `InventoryEvent` | RemoteFunction / RemoteEvent | `ReplicatedStorage/CharacterInventory` | `InventoryService` |
| `LeaderboardRequest` | RemoteFunction | `ReplicatedStorage/Leaderboard` | `LeaderboardService` |
| `Event` | RemoteEvent | `ReplicatedStorage/EggSteal` | server→client only (`EggStealService`) |

**Place-owned remotes.** These exist only in `result.rbxl` and code just references them: `CollectRiverEgg` (`PirateEggFreeConveyor`), `HatchCameraReady` (`HatchCameraGate`), `DropHeldItem` (`TwoHandItemCarryServer`), the GameMenu `GetState`/`Action` remotes (`GameMenuServer`), the owner-control remote (`OwnerControlServer`), the feedback remote (`FeedbackService`), `RiverEggCarryState`, `RiverEggPurchaseFeedback`, and `EggCollected`. Never delete these instances in Studio.

## Same-named modules (watch the path when requiring)

- `Config`: `ReplicatedFirst/LoadingScreen/Config`, `ReplicatedStorage/GameMenu/Config`, `ReplicatedStorage/JoinArrival/Config`.
- `PortalBuilder`: `ReplicatedStorage/Portal/PortalBuilder` **and** `ServerScriptService/Portal/PortalBuilder` (different files).
- `Style`, `Adapter`: `ReplicatedStorage/CharacterInfo/*` vs archived copies.
