# Molten texture source
Lava Texture by frema, licensed CC0 1.0.
https://frema.itlibra.com/en/asset/texture-lava

LavaCrustOriginal.png is the publisher's PNG512 variant. The 128 px game maps are mirrored and tiled, with a derived emissive fissure mask and tangent-space normals. The runtime map buffers are embedded in src/client/Effects/MoltenMapData.luau.
